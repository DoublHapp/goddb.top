# goddb.top 视觉重塑提案

本目录用于第一阶段视觉方向评审，不接入生产路由，也不修改 `frontend/`、`backend/` 或部署配置。

## 设计目标

- 面向兴趣内容读者，以“探索整站”为首页首要动作。
- 建立原创 DB 字母标识与“冷静又顽皮”的品牌人格。
- 以浅色编辑部信息骨架摆脱蓝紫渐变、霓虹发光和通用 AI 科技站观感。
- 用 P5/P4/JOJO 值得借鉴的构图与动效机制制造事件感，而不是复制其角色、Logo、截图、字体或原声。
- 桌面端允许高度沉浸，移动端使用同风格的轻量触摸反馈；声音默认关闭；低动态模式保留全部内容。

## 三稿比较轴

三稿使用相同内容、信息顺序与原创 DB 品牌母题，仅比较从克制到张扬的表达强度。

| 方案 | 定位 | 主要特征 |
|---|---|---|
| A 编辑台 | 最克制 | 十二列编辑网格、纸张层级、细黑线、红色切面 |
| B 怪盗通讯 | 平衡推荐 | 稳定内容网格、斜切导航、暖黄情报层、错位标题 |
| C 替身头版 | 最张扬 | 漫画分镜、集中线、事件异色、戏剧定格 |

## 共同内容

- 首屏提案文案：“认真不是访问本站的前置条件。”来源于现有个人简介的核心语义。
- 最新内容使用真实文章：《网站搬迁记：从 Vercel 到自建服务器》《零基础搭建 AI 回复语音 Demo》《为长期维护设计内容系统》。
- DB 宇宙使用真实的只狼与火影内容。
- 工具数据当前为空，因此只显示“建设中”，不伪造上线状态。

## 设计语言

- 浅色：暖纸白 `#F2EEDF`、墨黑 `#11100E`、档案灰 `#706C62`、怪盗红 `#E3312D`。
- 发现色：暖黄 `#F1CC2E`，仅用于情报、发现与辅助状态。
- 事件异色：紫或青只允许在 C 稿的短暂事件帧出现，不作为常驻蓝紫渐变背景。
- 字体候选：Archivo Black、Noto Sans SC、IBM Plex Mono，生产自托管前需再次核验许可证与子集体积。
- 星空只属于 DB 宇宙入口；水墨只作为短暂遮罩；网点、纸纤维和印刷错位不得覆盖正文。

## 互动分层

- L1：链接、按钮、卡片、键盘焦点和声音开关的即时反馈。
- L2：首页进入、导航换版、章节切换与移动菜单的短转场。
- L3：进入 DB 宇宙或发现彩蛋时的集中线、异色或水墨事件，不连续触发。
- `prefers-reduced-motion: reduce` 下，L2/L3 使用淡入、静态换色或固定构图替代。

## 评审方式

请从以下维度选择 A、B、C 或指定混合：

1. 是否摆脱蓝紫 AI 科技站和传统模板感。
2. DB 字标是否有独立品牌识别度。
3. 首屏是否能自然引导探索整站。
4. 游戏式表达是否压过内容阅读。
5. 视觉冲击强度是否适合长期浏览。
6. 桌面沉浸与移动轻量是否保持同一人格。

选稿后应明确保留元素、删除元素、可混入的其他稿元素、首屏文案修正和动效强度，再进入胜出方案的可点击原型阶段。

## 胜出融合原型

用户选择以 C 稿“替身头版”为主体，混入 B 稿“怪盗通讯”的斜切语言，并增加经典裂屏眼睛机制。融合结果位于：

- 可点击原型：`prototypes/concept-c-phantom-eye.html`
- 五阶段分镜源：`prototypes/concept-c-phantom-eye-storyboard.html`
- 桌面评审图：`exports/concept-c-phantom-eye-desktop.png`
- 移动评审图：`exports/concept-c-phantom-eye-mobile.png`
- 裂屏分镜图：`exports/concept-c-phantom-eye-storyboard.png`
- 午夜预览图：`exports/concept-c-phantom-eye-night-preview.png`

### 融合规则

- C 稿继续承担红色集中线舞台、漫画分镜、戏剧定格、超大标题和事件异色。
- B 稿只贡献黑色斜切页头、导航状态、箭头切口 CTA、黄色情报标签、任务卡与短促换版擦除。
- 正文和真实内容保持稳定网格，不让所有元素同时倾斜或运动。
- DB 宇宙 hover 可短暂切换紫/青事件色，离开后恢复纸白、黑、红、黄常态。

### 原创裂屏

开场采用五阶段状态机：

1. `idle`：红黑遮罩短预备。
2. `split`：非平行锯齿裂口快速打开。
3. `gaze`：原创漫画双眼进入主读帧。
4. `collapse`：裂口反向撕走，双眼向左上收束。
5. `brand-lock`：眼部几何落入红底 DB 方块并保持双眼常驻，首页恢复操作。

左瞳孔使用 D 的负形，右瞳孔使用 B 的双腔负形。眼型、裂口、碎片、瞳孔、节奏和运动路径均为原创 SVG/CSS，不使用 Persona 角色、原作眼图、裂纹、字体、音效、音乐或解包资产。

完整演出目标约 `0.98–1.08s`，并设有 `1.25s` 异常完成看门狗。同一标签页会话只自动播放一次；右上“重播开场”、左上 DB 徽记和控制面板均可重播；播放时可以点击跳过或按 Escape。

### 交互状态

- 频道卡片打开原型内任务面板，展示真实文章、DB 宇宙和项目内容；工具继续标记为建设中。
- 频道任务面板和午夜预览互斥，支持 Escape 关闭并将焦点还给触发按钮。
- 声音按钮只验证状态、文案、`aria-pressed` 与本地持久化，本原型不播放声音。
- 午夜按钮只打开黑、暖白、红、黄的组件预览，不代表完整双主题已经完成。
- 移动端使用单列漫画格、底部任务片和斜切菜单，不使用 pointer 跟随或持续视差。
- `prefers-reduced-motion: reduce` 下只显示静态双眼定格与淡出，不执行裂屏、推屏、旋转或飞入。

### 原型评审

下一轮应重点确认：

1. 裂屏冲击是否足够，是否需要调整凝视时长。
2. D/B 几何瞳孔是否有独立品牌识别度。
3. 双眼收束为红底常驻双眼的 DB 方块是否自然。
4. B 式斜切导航是否让 C 稿更像可操作网站而不是静态海报。
5. 首屏集中线与 `BREAK!` 是否仍然过度。
6. 频道任务面板和午夜预览是否值得进入生产实现。
